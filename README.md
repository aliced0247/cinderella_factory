# 👗 シンデレラ・ファクトリー

Factorioリスペクトの工場自動化ゲーム × お姫様成り上がり。
生産ラインで可愛い高級品を作って売り、名声と資金を貯めて、最終的に城でパーティーを開催して王子とお見合いする周回型ゲーム。

**現在：Phase 1（コア生産ループの試作）** — 進捗と質問は [STATUS.md](STATUS.md) 参照。

## 遊び方

`index.html` をブラウザで開くだけ（Phaser 3 同梱・サーバー不要・課金なし・セーブはlocalStorage）。
スマホ実機検品は `npx http-server -p 8080` → 同一Wi-Fiのスマホから `http://<PCのIP>:8080`。

- 下のパレットから設備を選んでマスをタップで設置（ベルトはドラッグで連続敷設）
- 魔法の泉 → ベルト → 研磨機 → ベルト → 納品箱 と繋ぐとお金（リル）が貯まる
- 設置済みをタップで「回転／撤去」、ピンチでズーム、左下スティックで姫が歩く

## 構成

```
index.html            … エントリ（script読み込み順もここ）
vendor/phaser.min.js  … Phaser 3.87.0（ローカル同梱）
src/
  config/   … データ定義（パレット40色・アイテム・設備・アセット表）
  core/     … プレースホルダー生成・セーブ
  systems/  … ワールド（グリッド）・物流シミュレーション
  scenes/   … Boot / Game / UI
tools/smoke-test.js … 実ブラウザ自動検証（要 playwright）
```

**素材差し替えは `src/config/assets.js` の `file` にパスを書くだけ**（コード変更不要）。
