# 👗 シンデレラ・ファクトリー

Factorioリスペクトの工場自動化ゲーム × お姫様成り上がり。
生産ラインで可愛い高級品を作って売り、名声と資金を貯めて、最終的に城でパーティーを開催して王子とお見合いする周回型ゲーム。

**現在：Phase 2（レシピ深化）** — 進捗と質問は [STATUS.md](STATUS.md) 参照。

## 遊び方

- **オンライン（推奨）**：https://aliced0247.github.io/cinderella_factory/
  （main にマージされると GitHub Actions が自動デプロイ。スマホでそのまま開ける）
- **ローカル**：`index.html` をブラウザで開くだけ（Phaser 3 同梱・サーバー不要・課金なし・セーブはlocalStorage）
- **同一Wi-Fiのスマホ実機**：`npx http-server -p 8080` → スマホから `http://<PCのIP>:8080`

- 初期所持 **100リル**。設備はリルで設置（ベルト2／納品箱10／研磨機20／ミシン25／工房台40／各泉50）。撤去で半額払い戻し（最後の泉だけ全額）
- 下のパレット（横スクロール）から設備を選んでタップで設置。ベルトはドラッグで連続敷設、リル不足のボタンはグレーアウト
- **2段加工**：絹糸の泉→ミシン（リボン/レース切替）／工房台で複数素材を合成（レース+リボン→ドレス等）。加工が深い高級品ほど高く売れる
- 設置済みをタップで「回転／レシピ切替／撤去」、ピンチでズーム、左下スティックで姫が歩く

## 構成

```
index.html            … エントリ（script読み込み順もここ）
vendor/phaser.min.js  … Phaser 3.87.0（ローカル同梱）
src/
  config/   … データ定義（パレット40色・アイテム・設備・アセット表）
  core/     … プレースホルダー生成・セーブ
  systems/  … ワールド（グリッド）・物流シミュレーション
  scenes/   … Boot / Game / UI
tools/smoke-test.js        … Phase 1 の実ブラウザ自動検証（要 playwright）
tools/smoke-test-phase2.js … Phase 2 の実ブラウザ自動検証（レシピ深化）
```

**素材差し替えは `src/config/assets.js` の `file` にパスを書くだけ**（コード変更不要）。
